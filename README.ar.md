# XXD Panel All · مهارة القائد العام

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md"><strong>العربية</strong></a>

`xxd-panel-all` هي المهارة القيادية ضمن عائلة XXD Panel. تبدأ بالتعرّف إلى مهارات الجنود `xxd-panel-NNN` المثبّتة في البيئة الحالية، ثم تتولى المهام التالية.

إذا وجدت نفسك أمام مجموعة من الصور من دون أن تعرف أي أسلوب يناسبها، وكانت تجربة كل أسلوب على حدة بطيئة والاختيار بالحدس وحده محفوفاً بالندم، فهذه المهارة تتولى عنك التقييم الأول. ما عليك سوى تقديم صورة أو مجلد؛ تفهم الطلب، وتختار الأنسب من لوحات Panel المثبّتة، وتوزّع العمل، ثم تجمع النتائج. لا تحتاج إلى حفظ الأرقام الـ154 مسبقاً.

### افهمها خلال 30 ثانية

- **لإنشاء صورة واحدة:** اذكر الموضوع أو أرسل صورة، فتقترح لوحات Panel المناسبة.
- **لمقارنة الأساليب:** حدّد عدة لوحات Panel لتجربة الصورة نفسها بكل واحدة منها.
- **للمعالجة على دفعات:** قدّم مجلداً، واستخدم إعدادات موحّدة أو عيّن لوحة مختلفة لكل صورة.

أسهل عبارة للبدء هي:

> هذه صورتي. أخبرني أولاً بلوحات Panel التي تقترحها ولماذا يناسب كل منها هذه الصورة.

تجد أدناه التفاصيل الكاملة للتثبيت، والمعالجة على دفعات، وإعدادات التفضيلات. غالباً ما يكون البدء بالاستخدام ثم العودة إلى التفاصيل عند الحاجة أسرع.

- اقتراح لوحات Panel بذكاء انطلاقاً من صورة أو موضوع
- تصفح الأساليب حسب الموضوع أو الإحساس البصري أو الاستخدام
- الإنشاء مباشرةً برقم Panel محدد
- تجربة مدخل واحد باستخدام عدة لوحات Panel
- إسناد كل صورة في مجلد إلى لوحة Panel مناسبة

تقتصر مهمتها على طرح الأسئلة والاختيار والتوجيه. وهي لا تتحول إلى أسلوب بصري جديد، ولا تقلّد لوحة غير مثبّتة اعتماداً على ملخص الكتالوج.

```bash

mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-panel-all" ~/.claude/skills/xxd-panel-all
```

إذا لم يكن `~/.codex/skills` مشتركاً مع `~/.claude/skills`، فأنشئ رابطاً إضافياً:


أعد فتح جلسة الـAgent بعد التثبيت، ثم استدعِ:

```text

```

## معالجة مجلد على دفعات

يمكنك تقديم مجلد الصور مباشرةً عند الاستدعاء:

```text
$xxd-panel-all /path/to/images
```

تدخل المهارة فوراً في وضع الدفعات، وتفحص الصور في المجلد ومجلداته الفرعية، ثم تطلب اختيار طريقة إسناد واحدة:

1. استخدام لوحة Panel واحدة لجميع الصور
2. مطابقة أفضل لوحة Panel تلقائياً مع كل صورة
3. تجميع الصور المتشابهة واستخدام لوحة واحدة لكل مجموعة
4. الإسناد التلقائي ضمن مجموعة محددة من لوحات Panel فقط

تُجمع إعدادات التسليم المشتركة مرة واحدة. وبعد ذلك تدخل كل صورة إلى `xxd-panel-NNN` المعيّن لها كمهمة مستقلة؛ لا تُدمج الصور في كولاج ولا تلوّث إحداها الأخرى.

## إعادة استخدام التفضيلات السابقة أو البدء بإعداد جديد

عندما تكون إعدادات التسليم الحالية غير مكتملة وتتوفر تفضيلات سابقة لـXXD Panel، يعرض القائد أو الجندي أولاً الأوضاع والأحجام والنص واللغة وعلاقة الخلفيات ومكان الإخراج السابقة، ثم يسأل:

1. **إعادة الاستخدام مباشرةً:** استخدام الإعدادات السابقة، مع إعطاء الأولوية للمتطلبات الحالية الصريحة.
2. **إعادة الاستخدام مع التعديل:** البدء بالإعدادات السابقة وتعديل الحقول المختارة فقط.
3. **إعداد جديد:** تجاهل السجل والاختيار من البداية.

ينفّذ الطلب المحدد بالكامل مباشرةً من دون أسئلة إضافية. ويمكن أيضاً استخدام `--prefs last|edit|new|off|clear` صراحةً. لا يحتفظ سجل التفضيلات إلا بإعدادات التسليم، ولا يحفظ الصور الأصلية أو النص الدقيق أو اختيار Panel أو النتائج المولدة أو مسارات النماذج أو بيانات اعتماد API أو أي معلومات حساسة أخرى.

```text
$xxd-panel-all /path/to/images --prefs last
$xxd-panel-all /path/to/images --prefs edit
$xxd-panel-all /path/to/images --prefs new
```

## حالة التثبيت

تكون لوحة Panel عند التشغيل في واحدة من ثلاث حالات:

- `AVAILABLE`: مثبّتة حالياً ويمكن استدعاؤها مباشرةً
- `KNOWN_BUT_MISSING`: موجودة في كتالوج الأساليب لكنها غير مثبّتة حالياً
- `UNKNOWN`: غير موجودة في الكتالوج

لا تستخدم التوصيات والإسناد على دفعات والإنشاء المباشر إلا لوحات Panel المثبّتة. يمكن تصفح الأساليب غير المثبّتة واقتراحها، لكن يجب تثبيت المهارة الفرعية المقابلة قبل الإنشاء.

## بنية المشروع

```text
xxd-panel-all/
├── SKILL.md
├── agents/
│   └── openai.yaml
├── references/
│   ├── panel-catalog.md
│   └── runtime-preferences.md
└── scripts/
    └── panel_preferences.py
```

- `SKILL.md`: قواعد التفاعل والاقتراح والتصفح والتوجيه على دفعات
- `panel-catalog.md`: كتالوج بحث محدّث حتى Panel 155، وليس موجّهاً لتوليد الصور
- `runtime-preferences.md`: حدود إعادة الاستخدام والتعديل والإعداد الجديد والخصوصية
- `panel_preferences.py`: أداة محلية لا تقرأ ولا تكتب إلا تفضيلات التسليم الآمنة
- `openai.yaml`: بيانات واجهة Skill الوصفية
